# Junior Go Backend Interview Prep

Репозиторий для системной подготовки к собеседованиям на позицию junior Go backend developer.

## Как заниматься

1. Идти по разделам сверху вниз, не пытаясь заполнить всё сразу.
2. В каждой теме написать короткую теорию своими словами.
3. Ответить на вопросы без конспекта.
4. Выполнить практические задачи и сохранить код, команды и наблюдения.
5. Отметить тему в [прогрессе](ROADMAP.md).

Материал внутри темы организуется одинаково:

- `README.md` — границы темы и порядок изучения;
- `overview.md` — связная справка: основные понятия, устройство и важные связи;
- `theory.md` — вопросы с собеседований и защит в формате «вопрос → ответ»;
- дополнительные файлы вроде `sql-guide.md` — углублённая справка по большой подтеме;
- `practice/` — неалгоритмические задачи и эксперименты;
- `notes.md` — ошибки, полезные команды и личные выводы (создаётся при необходимости).

Шаблоны для новых материалов лежат в [`templates/`](templates/README.md).

| Раздел | Что входит |

Алгоритмы и структуры данных намеренно не включены: для них лучше завести отдельный трек, чтобы практические backend-задачи не затерялись среди задач LeetCode.

## Правило готовности темы

Тема считается пройденной, когда можно:

- объяснить её за 3–5 минут без конспекта;
- ответить на контрольные вопросы;
- выполнить хотя бы одну практическую задачу;
- назвать типичную ошибку и способ её диагностировать.

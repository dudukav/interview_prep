# Go

Цель раздела — понимать поведение языка и уметь разбирать прикладной код, а не только воспроизводить синтаксис.

Материалы основаны на структуре [WatherMG/golang-book](https://github.com/WatherMG/golang-book), но переработаны под подготовку junior backend-разработчика и современный Go. Задачи из исходного репозитория не переносились.

## Подразделы

1. [Основы языка](01-language-basics/README.md) — типы, zero values, область видимости, функции, указатели.
2. [Коллекции и память](02-collections-and-memory/README.md) — arrays, slices, maps, strings, `new`/`make`, память и GC.
3. [Методы и интерфейсы](03-methods-and-interfaces/README.md) — method set, embedding, interfaces, type assertions, generics.
4. [Ошибки и context](04-errors-and-context/README.md) — wrapping, `errors.Is/As`, panic/recover, deadlines и отмена.
5. [Конкурентность](05-concurrency/README.md) — goroutines, channels, `select`, mutexes, races и остановка.
6. [Стандартная библиотека и I/O](06-stdlib-and-io/README.md) — `io`, файлы, JSON, время, `net/http`.
7. [Тестирование и диагностика](07-testing-and-debugging/README.md) — table-driven tests, fakes, benchmarks, race detector, pprof.
8. [Задачи с подвохом](08-interview-tasks/README.md) — чтение, изменение и исправление прикладного кода.

В каждом подразделе теория и контрольные вопросы находятся в `README.md`, а дополнительные задачи собраны в [общем практикуме](08-interview-tasks/README.md).

Отдельно: [частые ловушки на собеседованиях и тестах](interview-traps.md) — краткий справочник по всем темам с объяснением правильного хода мысли.

## Примеры неалгоритмических задач

- Предсказать вывод программы со `defer`, замыканием или nil-интерфейсом и объяснить результат.
- Найти data race и устранить его двумя способами.
- Реализовать worker pool с отменой через `context` и корректным завершением goroutines.
- Написать HTTP middleware для request ID, логирования и восстановления после panic.
- Найти утечку goroutine по тесту или профилю.
- Спроектировать интерфейс хранилища так, чтобы бизнес-логику можно было тестировать без БД.

## Минимальный результат

- небольшой Go-модуль с тестами;
- примеры ошибок и исправлений;
- команды `go test`, `go test -race`, `go vet`, форматирование и профилирование;
- ответы на вопросы в формулировках, понятных без знания конкретного проекта.

## Версия языка

Примеры рассчитаны на современный Go с модульной системой. Поведение переменных цикла изменилось начиная с Go 1.22: каждая итерация получает собственную переменную. Go 1.23 добавил range по iterator-функциям, а Go 1.27 — методы с собственными type parameters. Если задача зависит от версии языка, это указано явно.

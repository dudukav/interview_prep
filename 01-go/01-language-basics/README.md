# Основы языка

Собеседовательные нюансы: [затенение, defer, panic/recover, closures, копирование и порядок инициализации](../interview-traps.md#1-основы-языка).

## Структура программы

Go-код организован в packages. Каждый файл начинается с `package`, затем идут imports и declarations. Идентификатор, начинающийся с заглавной буквы, экспортируется из package. Функция `main` в package `main` служит точкой входа исполняемой программы.

Внутри package порядок файлов не определяет доступность объявлений: declarations package видны друг другу. Инициализация идёт по зависимостям packages, затем вычисляются package-level variables и выполняются функции `init`, после чего вызывается `main`.

## Переменные и zero value

Каждый тип имеет zero value:

| Тип | Zero value |
|---|---|
| числа | `0` |
| `bool` | `false` |
| `string` | `""` |
| pointer, slice, map, channel, function, interface | `nil` |
| struct/array | значение из zero values полей/элементов |

Zero value желательно делать полезным. Например, `sync.Mutex`, `bytes.Buffer` и `http.Client` можно использовать без constructor.

Основные формы объявления:

```go
var retries int          // 0
var host = "localhost"   // тип выведен
timeout := 2 * time.Second // только внутри функции
```

`:=` объявляет хотя бы одну новую переменную в текущей области. Оно может случайно затенить внешнюю переменную, особенно `err`.

## Именованные и определённые типы

```go
type UserID int64 // новый defined type
type ID = int64   // alias того же типа
```

`UserID` и `int64` имеют одинаковый underlying type, но это разные типы и требуют явного преобразования. Новый тип помогает не смешивать значения разного смысла и позволяет объявлять методы.

## Константы

Константы вычисляются во время компиляции. Нетипизированная константа получает конкретный тип из контекста и может хранить точное значение с большей промежуточной точностью, чем runtime-переменная.

`iota` увеличивается в каждой строке `const`-группы и удобна для связанных значений:

```go
type Status uint8

const (
    StatusUnknown Status = iota
    StatusNew
    StatusDone
)
```

## Управление потоком

У Go один вид цикла — `for`. `if` и `switch` могут начинаться с короткой инструкции, область видимости которой ограничена конструкцией:

```go
if value, ok := cache[key]; ok {
    return value
}
```

`switch` не проваливается в следующую ветвь автоматически. `range` работает с arrays, slices, strings, maps, channels и некоторыми современными iterator-формами. Порядок обхода map не определён.

## Указатели

Pointer хранит адрес значения. `&v` получает адрес, `*p` читает или изменяет значение по адресу. Pointer arithmetic в обычном Go отсутствует.

Передача pointer позволяет изменить объект и избежать копирования большой структуры, но увеличивает число разделяемых mutable values. Возвращать адрес локальной переменной безопасно: compiler разместит значение там, где оно проживёт достаточно долго.

`new(T)` выделяет zero value типа `T` и возвращает `*T`. В прикладном Go чаще достаточно `&T{...}`. `make` применяется только к slice, map и channel и инициализирует их внутреннюю структуру.

## Функции

Функции — значения: их можно передавать, возвращать и хранить. Closure захватывает переменные, а не снимок их значений. Захваченная переменная продолжает жить, пока доступна closure.

Go поддерживает несколько возвращаемых значений, что обычно используется для пары `value, error` или `value, ok`. Variadic-параметр внутри функции имеет вид slice.

## defer, panic и recover

Аргументы отложенного вызова вычисляются в момент выполнения `defer`, а сам вызов — при выходе из окружающей функции. Несколько `defer` выполняются в обратном порядке.

`panic` прекращает обычный ход функции и раскручивает stack, выполняя `defer`. `recover` способен остановить panic только при вызове из deferred function в той же goroutine. Panic не является обычным способом обработки ожидаемой ошибки.

## Область видимости и затенение

Scope — область исходного кода, где имя доступно. Lifetime — время существования значения в памяти. Это разные понятия.

Опасный пример:

```go
var err error
if enabled {
    value, err := load() // новый value и новый err внутри блока
    _ = value
    _ = err
}
// внешний err всё ещё nil
```
